# WetLSP v1.0 QC changes (branch `qc-outlier-fixes`) and differences from Moon et al. (2022)

**Summary:** WetLSP v1.0 (compared with v0.1) masks impossible reflectance and EVI values, fixes the MAD spike test, removes low-EVI dips that return to baseline (a "second-spline" filter), applies the dormant floor only outside the growing season, and fits the spline with upper-envelope reweighting. Every raw observation carries a QC flag.

## Paper-ready paragraph

> **Differences from the Moon et al. (2022) PlanetScope LSP workflow.** WetLSP v0.1 inherited the time-series screening and smoothing of the PLSP algorithm of Moon et al. (2022), which adapts Bolton et al. (2020): a local three-point despike that tests each observation against its immediate neighbours (combining a blue/red haze test, a linear-interpolation residual test and a double-difference MAD test), replacement of all values below a per-pixel dormant baseline (the 5th percentile of positive VI values) with that baseline, and a cubic smoothing spline (spar = 0.55) fitted with equal weights to target-year observations, with similarity-weighted observations from adjacent years used only to fill gaps longer than 20 days. WetLSP v0.1 also departed from PLSP in three ways. It used EVI rather than EVI2. It screened pixels with the UDM2 "clear" band alone, dropping PLSP's additional legacy-UDM test. It disabled PLSP's open-water check. Moon et al. (2022) applied the workflow at 104 AmeriFlux and NEON sites spanning a wide range of plant functional types, including grasslands and wetlands. In our pan-tropical-to-boreal wetland sites, however, persistent haze, cloud shadow, inundation and frequent cloud produced low-EVI artefacts that often span several consecutive acquisitions. A neighbour-based test cannot detect these. Clamping sub-baseline values to the dormant floor keeps in-season dropouts as if they were valid, and an unweighted spline lets them depress peak-season EVI. We also found that the despike's MAD test, as implemented in both PLSP and WetLSP v0.1, computed the MAD from EVI levels rather than from the double differences it tests, which effectively disabled it. WetLSP v1.0 therefore (1) masks non-physical reflectance (≤ 0) and EVI (outside −0.2 to 1) before screening; (2) corrects the scale estimate of the MAD spike test; (3) adds a per-pixel "second-spline" filter that removes negative departures from a robust running-median baseline only when a later observation returns to baseline, so sustained declines (mowing, flooding, senescence) are kept; (4) applies the dormant floor only outside the growing season and sets in-season sub-floor values to missing; and (5) fits the spline with iterative upper-envelope reweighting (cf. Chen et al., 2004). Each raw observation carries a QC flag recording why it was retained, floored or removed.

## Step-by-step comparison

| Step | Moon et al. (2022) / PLSP | WetLSP v0.1 (`c50f58c`) | WetLSP v1.0 (`qc-outlier-fixes`) |
|---|---|---|---|
| Vegetation index | EVI2 (paper, "Creation of daily EVI2 time series"; `PLSP_Functions.R:537`) | EVI (`wetlsp-functions.R:540`) | EVI (unchanged) |
| Pixel mask | Legacy UDM `> 0` and UDM2 band 1 (clear) `!= 1` set to NA. An image is kept unmasked if the UDM2 read fails (`Code_LSP/01_img_process.R:148,158,161–167`) | UDM2 clear band only. An image is kept unmasked if UDM2 is missing or fails (`01-wetlsp-process.R:261–306`) | Unchanged (a tighter mask needs step 01 rerun) |
| Non-physical values | None explicit. `maskNegativeValues` exists in the JSON but no code reads it. Negative VI is floored, not removed | Same | Band ≤ 0 or NA, and EVI non-finite or outside [`eviValidMin` −0.2, `eviValidMax` 1], set to NA. `maskNegativeValues` (true) is now wired up |
| Fill/overflow values | None | None. Tellabs step-02 chunks contain 4294967296 (2^32) in all four bands, which gives EVI exactly 0 | Reflectance > `reflectanceValidMax` (1.5) set to NA; exact-zero EVI set to NA (`maskExactZeroVI` true) |
| Published spline coverage | — | The spline is written for every `phenYr` the fit succeeds for, including years with no imagery (extrapolated through the 185-day buffer, e.g. US-Alq 2025). Leap years lose Dec 31 (fixed 365-day `inYear` index) | Target year chosen by date (includes Dec 31). Spline set to NA more than `splineExtrapolateDays` (20) beyond the first or last valid observation (`maskSplineOutsideData` true) |
| Open-water check | Pixel → QA 4 if > `sumNegVIthresh` (0.5) of VI < 0 and water occurrence > 30 (`PLSP_Functions.R:541`) | Commented out, and `waterMask = 0` is hard-coded (`03-wetlsp-phenometrics.R:185,223`) | Unchanged |
| Despike | 3-point `majaTest`, `eTest`, `madTest`, iterated up to 50 times; `minResid` 0.1, `spikeThresh` 2, `maxDistance` 45, `MADspikeThresh` 2 (`PLSP_Functions.R:15–85`) | Identical | Identical apart from the MAD fix |
| MAD scale | `median(abs(eS[ind2]-Md))`, i.e. EVI levels, so the test is effectively disabled (`PLSP_Functions.R:70`) | Same bug (`wetlsp-functions.R:70`) | `median(abs(eDiff - Md))`. `MADspikeThresh` default raised to 4 |
| Dip filter | None | None | `SecondSplineQC`: `secondSplineQC` true, `ssqcMinAbs` 0.12, `ssqcK` 4, `ssqcWindowObs` 11 (or `ssqcWindowHalfDays`), `ssqcReturnObs` 3, `ssqcReturnDays` 20, `ssqcMaxIter` 3 |
| Dormant floor | `vi[vi < vi_dorm] <- vi_dorm` on all dates, where `vi_dorm` = `dormantQuantile` (0.05) of positive VI (`PLSP_Functions.R:551–552`). The paper says 10th percentile of snow-free values; the code uses 0.05 and has no snow test | Same; window `dormStart`/`dormEnd` 2021–2024, no NA guard (`wetlsp-functions.R:557–559`) | `dormantFloorMode` `"offseason"`: floored outside the season, NA in season (`growingSeasonFrac` 0.25). `"all"` gives the old behaviour. `vi_dorm` NA guard added |
| Spline | `smooth.spline`, `splineSpar` 0.55, weights 1 in the target year (`PLSP_Functions.R:98,632`). Years with gaps > 20 d are refit with adjacent-year observations weighted by curve similarity (`maxWeight` 0.5, `PLSP_Functions.R:486–517,688–704`). Output clamped at `vi_dorm` (`:102`) | Same | Plus upper-envelope reweighting: `envelopeReweight` true, `envelopeIterations` 3, `envelopeMinWeight` 0.1 |
| Per-observation QC | None (pixel QA 1–4 from fit R² and gaps only) | None | `qc_raw`: 0 ok, 1 invalid, 2 despike, 3 second-spline, 4 in-season sub-floor → NA, 5 floored (optional `.rds` column; parquet schema unchanged) |
